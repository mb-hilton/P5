# 5‑Bedroom Oceanfront Penthouse  
### DoubleTree by Hilton • Ocean City, Maryland  
**3301 Atlantic Ave, Ocean City MD 21842**

This repository contains a fully static website showcasing the 5‑bedroom oceanfront penthouse at the DoubleTree by Hilton in Ocean City, MD.

## 📁 Structure
- `index.html` — main site
- `styles.css` — responsive styling
- `/images/` — all property photos
- `README.md` — project documentation

## 🌐 Deployment (GitHub Pages)
1. Go to **Settings → Pages**
2. Under **Build and Deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
3. Save and wait 30–60 seconds.

Your site will appear at:
http://mb-hilton.github.io/p5
